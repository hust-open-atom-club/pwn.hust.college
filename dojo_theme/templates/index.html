欢迎来到 pwn.hust.college

pwn.hust.college 是一个基于神奇宝贝游戏设计的CTF趣味教育平台，供学生们学习和动手实践网络空间安全安全的核心概念。在平台中，同学们将化身为神奇宝贝训练家，通过挑战神奇宝贝道馆实践理论课堂中学习到的核心安全攻防技术，获取相应道馆徽章，最终成长为技术娴熟的白帽黑客。我们平台的设计理念为 未知攻焉知防、实践出真知 与 寓教于乐，旨在让同学们在玩游戏中动手实践网络空间安全中的攻防理论知识和技能。

本平台由华中科技大学网络空间安全学院的出色白帽黑客团队维护。目前该平台支撑网安学院的软件安全理论课程与实践课程，且免费开源。

如果您对本平台有任何意见、建议或反馈，请通过 pwn_hust_college@hust.edu.cn 邮箱联系我们或在本平台 Git 仓库中提交 issues。



基本规则

pwn.hust.college 创建的挑战关卡是教育素材，用于给华中科技大学网络空间安全学院的学生评分。因此，我们希望不要在互联网上发布这些挑战关卡的通关攻略、讲解视频和直播。显然，我们无法阻止您在互联网上发布内容，但我们努力使所有这些内容都变成公开的，我们希望您的帮助能够使 pwn.hust.college 保持为一个可行的教育平台。



神奇宝贝道馆

在开展正式道馆挑战之前，我们先来介绍一下神奇宝贝道馆。每个神奇宝贝道馆都有一位馆主及其独特属性的神奇宝贝，同学们需要通关道馆挑战关卡，击败道馆馆主才能获得道馆徽章。注意，只有集齐 8 枚徽章的神奇宝贝训练家才能参加最终的神奇宝贝联盟大会。加油吧，各位神奇宝贝训练家！


徽章（Badge）

徽章作为神奇宝贝训练家通过道馆馆主考验的标志，是大家参加神奇宝贝联盟大会的入场券，同时，也是神奇宝贝训练家的实力象征。为了激励大家学习热情，我们将制作好真实的道馆徽章，发放给完成道馆挑战的神奇宝贝训练家。


如何获得真实道馆徽章？

一旦您完成所有必需的挑战关卡在平台中获得道馆徽章，您可以通过 pwn.hust.college 平台注册账号的关联邮件账号发送邮件给我们，获取真实徽章！

高级篇

神奇宝贝联盟大会（Pokémon League Conference）是宝可梦动画中的宝可梦联盟比赛，在每个地区都有例行性的举办。若要取得参赛资格，通常要在联盟举办前，取得当地 8 枚以上的道馆徽章。



学习深造

当您学习完网络空间安全的基础知识并获得基础徽章后，您可以挑战更难的关卡！

CTF 是一个很好的方式，可以在有趣和合法的情况下练习您的黑客技能。查找即将举行的 CTF 活动的最流行的方式是在 https://ctftime.org，这里还有一个初学者 CTF 列表。如果您在华中科技大学学习，欢迎加入 L3H CTF 俱乐部。

如果您想参与网络空间安全方面的研究，但不知道如何入门，请考虑加入我们课题组实习，并联系我们。



贡献

pwn.hust.college 基础架构及相关道馆仓库均开源在 华中科技大学开放原子开源俱乐部组织，欢迎大家提交 PR 和 issue。然而，道馆仓库中不包含 write-up 或 solution。如果您是一位教育工作者，或者其他我们信任的人，并且对与神奇宝贝模块素材的合作感兴趣，可通过邮箱联系我们。

如果您想参与贡献，请遵循 “上游优先” 原则，优先贡献由亚利桑那州立大学创建的上游 pwn.collge 平台。如果是 pwn.hust.college 平台上的特定问题或参与该平台的开源贡献，请提交 issues 或 PR 到我们的仓库。非常感谢！
